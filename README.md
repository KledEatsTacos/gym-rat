# Gym Rat - Fitness Center Management System

A comprehensive web application for managing gym operations, built with ASP.NET Core 8.0 MVC.

## 🚀 Features

### 🏋️‍♂️ Gym & Trainer Management
- **Single Gym Architecture:** Designed for "GymRat Fitness Center".
- **Trainer Management:** Track trainers, specialties, and working hours (08:00 - 22:00).
- **Service Management:** Define classes (Pilates, Yoga) and personal training options with prices and durations.

### 📅 Smart Appointment System
- **Dynamic Availability:** Real-time checking of trainer capability. Booked slots are automatically removed from the selection.
- **Conflict Prevention:** Logic ensures no double-booking for trainers.
- **Admin Approval:** Appointments start as "Pending" and require Admin confirmation.

### 🤖 AI Integration
- **Personalized Plans:** Users input their stats (weight, goal, etc.) and get a custom workout/diet plan generated by **Llama 3 70B (via Groq)**.
- **Visual Motivation:** Generates a motivational fitness image using **Stable Diffusion XL** based on the plan.

### 👑 Admin Dashboard
- Centralized hub (`/Admin`) for gym managers.
- Live statistics on members, trainers, and appointments.
- Quick actions for daily tasks.

## 🛠️ Tech Stack
- **Framework:** ASP.NET Core 8.0 MVC
- **Database:** PostgreSQL (Entity Framework Core)
- **Frontend:** Bootstrap 5, JavaScript (AJAX for dynamic slots)
- **AI Services:**
  - Text: Groq API (Llama 3)
  - Image: Hugging Face Inference API (SDXL)
- **Auth:** ASP.NET Core Identity (Role-based: Admin/Member)

## 👤 User Roles
- **Admin:** Full control. Can manage trainers, services, and approve appointments. exists as `G221210580@sakarya.edu.tr`.
- **Member:** Can register, view trainers/services, book appointments, and use AI features.

## 📦 Database Setup
The application uses a seeded initializer to ensure the Admin user and default data (Gym info, sample trainers/services) exist on first run.
